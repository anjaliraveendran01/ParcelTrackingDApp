# Blockchain-Based Parcel Tracking System

## Project Description
This project is a decentralized application (DApp) that uses blockchain technology to track parcels. It allows users to register parcels, update their delivery status, and check parcel details.

## Technologies Used
- Solidity
- Ethereum Blockchain
- Sepolia Test Network
- MetaMask
- Remix IDE
- HTML
- CSS
- JavaScript
- Ethers.js

## Features
- Connect MetaMask wallet
- Register a new parcel
- Update parcel delivery status
- Track parcels using a tracking ID
- Store parcel information on the blockchain

## Smart Contract
- Network: Sepolia Test Network
- Contract Address: 0x61eaC74029CBf9F450C6c5CD602938382f36B567

## How to Run
1. Install MetaMask in your browser.
2. Select the Sepolia Test Network.
3. Open the project using VS Code.
4. Start the website using Live Server.
5. Connect your MetaMask wallet.
6. Register, update, and track parcels.
